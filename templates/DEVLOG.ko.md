# DEVLOG 설정

devlog 스킬이 일지를 쓰기 전에 매번 이 파일을 읽어. 자유롭게 고쳐도 돼.

## 프로젝트
name: 내 프로젝트
description: 프로젝트를 한 줄로 설명

## 출력
language: ko          # 일지를 쓸 언어 (ko, en, ja …)
folder: devlog        # 일지, map.json, dashboard.html이 저장될 폴더
dashboard: manual     # manual = 요청할 때만 만들기, auto = 일지 쓸 때마다 다시 만들기

## 태그
# 일지에 태그를 달 때 여기서 골라. 직접 추가해도 돼.
- 백엔드
- 프론트엔드
- 데이터
- 인프라
- 공부

## 기록 금지
# 대화에 나왔더라도 여기 적힌 건 일지에 남기지 않아.
- API 키, 토큰, 비밀번호
- 내부 URL, 서버 주소
- 팀원 실명 (역할로 대신 쓰기)
- 고객·개인 정보
